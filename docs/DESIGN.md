# 화면 디자인 사양 — *Hollywood Merge* 의 "보이는 것" 만 옮기기

## 출처와 범위

- 참고작: **Hollywood Merge** (VoyagerOne, iOS/Android, 한국어 지원). 옷장 화면
  스크린샷 7장(드레스·구두·바지·머리·분류 레일·외투·상의)을 기준으로 삼았다.
- 가져온 것은 **화면 구성·색·버튼 모양·효과** 뿐이다. 머지 보드·에너지·보석 구매·
  스토리·한정 판매·광고는 가져오지 않는다 — 이 게임의 "실패 없음·구매 없음·
  한 손가락" 원칙과 부딪힌다.
- 인형도 참고작처럼 **키 큰 패션 아바타(약 8등신)** 로 바꿨다. 3D 렌더는
  아니고 벡터지만 비율·얼굴(아몬드 눈·청회색 홍채·속눈썹·입술)·긴 머리를
  참고작 쪽으로 맞췄다. 좌표계는 docs/DOLL.md.

## 스크린샷에서 읽어낸 것

측정치는 스크린샷(858 x 2000)을 논리 화면(360 x 640)으로 환산했다. 참고작은
9:21 이고 우리는 9:16 이라 세로는 비율로, 가로는 1:1 로 옮겼다.

### 1. 전체 톤

| 항목 | 참고작 | 지금(교체 전) |
|---|---|---|
| 바탕 | 배경 그림이 화면 전체. UI 는 그 위에 반투명 판 | 짙은 자주 단색 + 무대만 그림 |
| 색조 | 노을 분홍·살구 하늘, 보라빛 도시, 베이지 마루 | 보라·자주 어둡게 |
| 글자 | 진한 자두색 또는 흰색. 제목은 **금색 + 갈색 외곽선** | 흰색 |
| 포인트 | 핑크레드(뒤로) · 라임그린(확인·체크) · 금색(선택) · 라벤더회색(태그) | 분홍·민트·보라 |
| 패널 | 흰색 85~90%, 반지름 14 이상, 연한 그림자 | 흰색 12% 유리판 |

### 2. 상단 HUD

- 좌상단 **재화 pill**: 보석 아이콘 + 숫자 + 초록 ⊕. 크림색 바탕.
  → 우리: **스티커 수** (🌈 N). ⊕ 는 없다(살 게 없다).
- 그 아래 **뒤로 버튼**: 핑크레드 둥근 사각(왼쪽 모서리 직각), 흰 굽은 화살표.
  → 모든 화면 같은 자리. 아이가 길을 잃으면 여기.
- 가운데 **제목**: 금색 굵은 글씨 + 갈색 외곽선. 그 아래 **태그 pill**(라벤더 회색
  70%, 흰 글자, 🏷 아이콘).
  → 우리: 제목 = 놀이 이름, pill = 지금 보는 분류(옷장) 또는 부제.
- 우상단 **원형 회색 버튼**(!). → 우리: 🔊 소리 켜고 끄기.

### 3. 무대

- 인형이 화면 왼쪽 2/3, 거의 전체 높이. 배경이 상단바 뒤까지 깔린다.
- 배경: **옥상 파티** — 노을 하늘, 불 켜진 창문의 도시 실루엣과 높은 탑, 풍선,
  테이블보를 덮은 둥근 테이블, 헤링본 마루. **꽃잎이 계속 떨어진다.**
- 발밑 그림자.

### 4. 오른쪽 조작부 (세 열)

| 열 | 참고작 | 우리 |
|---|---|---|
| 분류 레일 | 원형(≈44) 세로 일렬, 연분홍 바탕 + 흰 테두리, 자두색 아이콘. 착용 중이면 우하단 **초록 ✓ 배지**, 개수는 숫자 배지 | 10 분류 그대로. 착용 ✓ 배지 |
| 아이템 목록 | 세로 한 열, 칸 ≈ 70 x 62, 연라벤더 둥근 사각. 선택 칸은 **금색 방사형 빛남 + 흰 테두리**. 희귀는 우하단 민트 삼각 리본. 위에 정렬 드롭다운("최근 획득 ▼"), 옆에 ▲▼ | 6칸/페이지 + ▲▼. 드롭다운 대신 분류 이름 pill. 리본은 "내가 만든 왕관" 표시 |
| 색 견본 | 흰 pill 안에 원 6개(≈30), 선택에 흰 ✓. 분류마다 팔레트가 다름 | **새 기능**: 드레스·머리·구두·망토 색 바꾸기. 패션쇼는 원래 색으로 판정·표시 |

### 5. 하단

- 좌하단 **원형 유리 버튼**(↺). → 우리: 도구 5개를 원형으로 (🎲 ↺ 🌈 📷 🖼).

## 적용 — 화면별 배치 (360 x 640)

숫자의 원본은 `src/ui/*Screen.ts` 와 `src/render/ui.ts` 의 상수다. 여기는 읽기용.

### 나머지 화면

- 배경 고르기·룩북·미션 목록·결과·공방·방·앨범은 **배치는 두고 색·판·버튼만**
  새 테마로 바꾼다. 네 살이 익힌 자리를 옮기지 않기 위해서다.
- 공방·방·앨범 바탕은 각각 노을·연분홍·라벤더 하늘 그라데이션 + 꽃잎 없음.

## 가져오지 않은 것과 이유

| 참고작 | 왜 안 가져오나 |
|---|---|
| 3D 렌더 | 이미지 에셋 없이 벡터로 그리는 구조를 유지. 비율·얼굴만 맞췄다 |
| 세로 스크롤 | 아이는 스크롤에서 길을 잃는다. 페이지 화살표 유지 |
| 정렬 드롭다운 | 58벌엔 필요 없다 |
| 보석·에너지·구매·광고 | 구매 없음 원칙 |
| 한정 의상 | 모든 옷이 처음부터 열려 있다. "잠금 없음" 원칙 |
| 메이크업·악세사리 분류 추가 | 이번 범위 밖. 분류는 10개 유지 |

## 구현 메모

- 테마 상수는 `src/render/ui.ts` 의 `UI` 한 곳에 둔다. 화면이 색을 직접 적지 않는다.
- 색 바꾸기는 `src/engine/color.ts` 가 Shape 의 fill/stroke 를 **색조만 돌린다**.
  채도가 낮은 색(흰 레이스·회색 테두리)은 그대로 둬야 장식이 살아남는다.
- 색 선택은 `closet.tints` 에 분류별 견본 번호로 저장한다. 0 = 원래 색.
  룩북에도 같이 담긴다. 패션쇼는 색 태그로 채점하므로 **원래 색으로 그린다.**
- 배경 7종. `party`(옥상 파티)가 새 기본값이다. 기존 6종 아이디는 그대로.
