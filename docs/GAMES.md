# 놀이 다섯 가지

## 무엇을 참고했나

페파피그 계열 유아 게임(예: *Peppa Pig: World Adventures*)에서 아이를 붙잡아
두는 장치를 뽑아 옮겼다. 그대로 베낀 것은 없고, 통하는 구조만 가져왔다.
화면 **생김새**는 *Hollywood Merge* 의 옷장 화면을 참고했다 — 무엇을 어떻게
옮겼고 무엇을 일부러 안 가져왔는지는 [DESIGN.md](DESIGN.md) 에 있다.

| 참고한 요소 | 이 게임에서 |
|---|---|
| 실패·게임오버가 없다 | 패션쇼도 별이 덜 붙을 뿐 지지 않는다. 다시 하기가 항상 있다 |
| 원터치·큰 버튼 | 모든 버튼이 최소 20px, 조작은 "누르기" 하나 (옮기기만 끌기) |
| 화면이 말을 건다 | 말풍선으로 리아가 계속 반응한다 (`👗 별빛 파랑 드레스 예쁘다!`) |
| 모으기 | 스티커 24장을 네 놀이에 걸쳐 모은다 |
| 자유 놀이 + 과제 놀이 | 옷장·방은 목표 없음, 패션쇼는 부탁 20개 |
| 여러 장소로 여행 | 배경 7곳 (옥상 파티·무도회장·정원·바닷속·눈나라·별밤·사막) |
| 꾸민 걸 남긴다 | 룩북 9장에 코디를 사진처럼 담는다 |
| 놀이끼리 이어진다 | 공방에서 만든 왕관이 옷장에 아이템으로 들어간다 |
| 축하 연출 | 색종이·반짝이·팡파레 |
| 잠금 없음 | 미션이 잠기지 않는다. 20번을 먼저 해도 된다 |

## 1. 공주 옷장 (`closet`)

자유 놀이. 10개 분류 · 58종을 마음대로 겹쳐 입힌다.

- 오른쪽 레일에서 분류를 고르고, 세로 목록에서 옷을 누른다. 입고 있는 분류엔
  초록 ✓ 배지가 붙는다.
- 같은 옷을 다시 누르면 벗는다.
- 🎨 색 견본 — 드레스·머리·구두·망토는 여섯 색으로 바꿀 수 있다. 옷 그림의
  색조만 돌리므로 흰 레이스는 그대로 남는다. ↺ 를 누르면 원래 색. 저장값은
  분류별 견본 번호뿐이다 (`closet.tints`).
- 🎲 랜덤 — 드레스와 머리는 반드시 채우고 나머지는 확률로. 아무것도 안 바뀌면
  "고장 났다" 로 읽히기 때문이다.
- ↺ 다벗기 · 🌈 배경 · 📷 사진(룩북에 담기) · 🖼 룩북(누르면 그 코디로 갈아입기)
- 룩북은 9장이 차면 가장 오래된 것을 밀어낸다. "자리가 없어요" 로 막지 않는다.
  색 견본도 같이 담긴다.

## 2. 패션쇼 (`runway`)

부탁을 듣고 코디를 맞춘다. 미션 20개.

조건은 네 가지 결로 만든다.

| 종류 | 예 |
|---|---|
| `item` | 유리 구두를 신어줘 |
| `cat` | 왕관을 써줘 (아무 왕관이나) |
| `color` | 파란색 물건을 걸쳐줘 |
| `theme` | 눈나라 느낌으로 |
| `count` | 여덟 칸 이상 채워줘 |

- 조건 칩에 ✓ 가 실시간으로 붙는다. 맞출 때마다 별이 튄다.
- 색 견본은 없고 **원래 색으로 그린다.** 채점이 색 태그로 되는데 분홍으로
  물들인 파란 드레스에 "파란색 ✓" 가 붙으면 아이가 헷갈린다.
- 채점: 전부 맞으면 ⭐⭐⭐, 절반 이상 ⭐⭐, 하나라도 ⭐, 없으면 격려만.
- 최고 기록만 남는다. 이미 별 셋인 미션을 다시 하다 깎이면 억울하다.
- 💡 힌트를 누르면 아직 못 맞춘 조건 하나에 금색 테두리가 켜진다.

테스트가 **미션 20개 전부 실제로 별 셋을 받을 수 있는지** 코디를 조립해 확인한다.
옷을 지우거나 태그를 바꿔 깰 수 없는 미션이 생기면 바로 빨간불이 켜진다.

## 3. 보석 왕관 공방 (`crown`)

보석 8종 · 바탕 3종 · 칸 8개.

- 보석을 고르고 왕관의 빈 칸을 두드리면 붙는다. 끌어다 놓기를 쓰지 않는 이유는
  네 살 손가락으로 정확히 끌기가 어렵기 때문이다.
- 🧽 지우개로 하나씩 빼고, ↺ 다지우기로 전부 지운다.
- 💾 옷장에 — 저장하면 **옷장 왕관 칸에 아이템으로 들어가고 즉시 리아가 쓴다.**
  세 자리까지, 넘치면 가장 오래된 것이 밀린다.
- 저장한 왕관을 누르면 다시 꺼내 고칠 수 있다.

## 4. 공주 방 꾸미기 (`room`)

가구 16종을 18개까지 놓는다.

- 창고에서 고르고 방을 두드리면 놓인다. 놓인 가구는 끌어서 옮긴다.
- 벽 가구(거울·액자·창문·샹들리에)와 바닥 가구는 놓이는 높이 구간이 다르다.
  침대가 벽에 붙어 뜨면 아이가 이상하다고 느낀다.
- 앞뒤는 y 로 정렬한다. 아래에 있는 물건이 앞에 그려진다.
- ↺ 다치우기는 두 번 눌러야 지워진다.
- 리아가 지금 입은 옷 그대로 방 오른쪽에 서 있다.

## 5. 스티커 앨범 (`album`)

24장. 못 받은 것도 회색으로 자리를 보여 주고, 누르면 힌트가 나온다.
빈칸이 보여야 "저건 어떻게 받지?" 하고 다시 놀러 간다.

마지막 한 장(`반짝반짝 리아`)은 나머지 23장을 모두 모으면 붙는다.

## 소리

음원 파일이 없다. WebAudio 로 그때그때 합성한다(`src/core/audio.ts`).

- 효과음 13종: 옷 입기·벗기·반짝임·보석·사진·별·팡파레·스티커 …
- 배경음 2곡: `closet`(느리고 포근한 장조) · `show`(경쾌한 왈츠풍)
- iOS 는 사용자가 화면을 한 번 눌러야 소리를 허용한다. 첫 터치에서 잠금을 푼다.
