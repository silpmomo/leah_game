# 인형과 옷

## 왜 도트가 아닌가

리온의 대모험은 스프라이트 시트를 구워 썼다. 옷입히기에 같은 방식을 쓰면

- 옷 한 벌마다 프레임을 굽고, 색만 다른 옷에도 새 프레임이 필요하고
- 옷을 겹칠 때마다 조합이 늘어나고
- 세로 화면 크기가 기기마다 달라 정수 배율을 맞추기 어렵다.

그래서 여기서는 **SVG 경로 문자열 + 칠하기 정보**(`Shape`)를 데이터로 들고,
브라우저에서 `Path2D` 로 그린다. 덕분에

- 옷을 "실루엣 + 색 3개 + 목선 + 장식" 같은 사양으로 찍어낼 수 있고
- 그림 정의가 전부 순수 모듈이라 node 테스트에서 검증되고
- 아무리 확대해도 깨지지 않는다.

## 좌표계

아바타는 **200 x 440** 상자 안에 서 있다 — 머리 하나가 키의 1/8 쯤인 패션
아바타다(참고작 Hollywood Merge, docs/DESIGN.md). 예전 치비 인형(200 x 340,
머리가 키의 1/3)에서 바꿨고, 옷 생성기도 전부 새 좌표로 다시 그렸다.
`src/doll/body.ts` 의 `A` 가 자리표다.

```
 y=28   머리카락 꼭대기 (hairTop)
 y=38   왕관 띠 꼭대기 (headArc: 78,50 → 100,26 → 122,50)
 y=64   얼굴 중심
 y=66   눈
 y=70   귓불 (귀걸이)
 y=91   턱
 y=104  옷깃
 y=112  어깨
 y=140  가슴
 y=172  허리
 y=202  엉덩이
 y=226  손
 y=300  무릎
 y=392  발목
 y=416  발끝
 y=418  그림자
```

가로는 `x=100` 이 한가운데다. 좌우 대칭이 필요하면 `200 - x` 를 쓴다.
팔은 `ARM_L` / `ARM_R`(어깨 → 팔꿈치 조절점 → 손) 곡선이고, 장갑·긴 소매는
그 곡선의 일부를 잘라 쓴다(`armFrom`).

## 층 번호

`composeDoll()` 이 이 순서로 조각을 이어 붙인다. **순서가 곧 앞뒤다.**

| 층 | 내용 |
|---|---|
| 10 | 날개 (`wings.back`) |
| 20 | 망토 천 (`cape.back`) |
| 25 | 뒷머리 — 머리 아이템의 `back`, 없으면 기본 뒷머리 |
| 30 | 몸 (다리·몸통·목·귀·머리통) |
| 34 | 얼굴 |
| 38 | 기본 옷 (흰 티 + 라벤더 치마) — **드레스를 입으면 생략** |
| 42 | 드레스 (`dress.front`) |
| 46 | 기본 신발 → 구두 아이템 |
| 50 | 팔과 손 |
| 54 | 소매 — 드레스의 `sleeves`, 드레스가 없으면 기본 반팔 |
| 58 | 장갑 (`gloves.sleeves`) |
| 62 | 앞머리 — 머리 아이템의 `front`, 없으면 기본 앞머리 |
| 64 | 망토 깃 |
| 66 | 귀걸이 |
| 68 | 목걸이 |
| 72 | 왕관 |
| 76 | 손에 드는 소품 |

두 가지가 이 표에서 중요하다.

1. **팔은 몸과 따로 그린다(50층).** 몸에 붙여 한 번에 그리면 드레스 치마가
   팔뚝을 덮어 손이 사라진다. 처음에 그렇게 만들었다가 고쳤다.
2. **드레스를 입으면 기본 옷을 감춘다.** 겹쳐 두면 인어 드레스처럼 폭이 좁은
   옷 옆으로 라벤더 치마가 삐져나온다. 기본 옷은 "아무것도 안 입혔을 때의
   리아" 이고, 드레스는 그걸 갈아입는 것이다.

## 옷 한 벌 추가하기

`src/doll/wardrobe.ts` 의 표에 한 줄을 넣는다. 그림은 `builders.ts` 가 만든다.

```ts
dress(
  { id: 'dress-mint-bell', name: '민트 종 드레스', color: 'green', theme: 'flower' },
  {
    silhouette: 'ballgown',   // ballgown · gown · aline · mermaid · pants
    main: '#8fe0c0',
    dark: '#4fae90',
    trim: '#e8fff6',
    neckline: 'puff',        // puff · off · strap · long · halter
    deco: 'flower' 대신 'rose' 같은 기존 값 중 하나,
    decoColor: '#ffffff',
  },
),
```

- **아이디는 절대 바꾸지 않는다.** 저장된 코디와 룩북이 아이디로 옷을 기억한다.
- `color` · `theme` 태그는 패션쇼 미션 조건에 쓰인다. 빠뜨리면 그 옷으로는
  "파란색 옷을 입어줘" 같은 미션을 깰 수 없다.
- 새 실루엣이나 장식이 필요하면 `builders.ts` 의 `switch` 에 갈래를 하나 더 만든다.
- `npm test` 가 데이터를 검사한다. 부팅할 때도 `assertValidWardrobe` 가 한 번 더 본다 —
  검은 화면 대신 무엇이 잘못됐는지 글로 보여 준다.

## 표정

`faceShapes(expr)` 에 다섯 가지가 있다: `smile` · `happy` · `wink` · `surprise` ·
`sparkle`. 옷을 입히면 잠깐 `happy` 로 바뀌었다가 돌아온다. 눈썹은 양 끝 높이를
같게 그린다 — 한쪽만 올리면 좌우가 나란히 기울어 비웃는 얼굴이 된다.
