# 인형과 옷

## 그림은 어디서 오나

인형·옷은 **일러스트 조각(WebP)** 을 겹쳐 그린다. 왕관·날개·손 소품만 벡터다.

| 무엇 | 출처 | 어디에 |
|---|---|---|
| 몸·얼굴·머리·옷·구두·목걸이·장갑·망토·귀걸이 | MaelleMarylloup 의 CHIBI 무료 팩 7종 (itch.io) | 비공개 저장소 `silpmomo/leah_game_assets` |
| 왕관·날개·지팡이, 왕관 공방 왕관 | `src/doll/builders.ts` (벡터) | 이 저장소 |
| `gen-*` 조각 (하트 티아라·하트 요술봉·분홍 나비 날개) | ChatGPT 이미지 생성 (`gen/prompts.md`) | 비공개 저장소 `gen/in/` |

- 팩 라이선스: 개인·상업 사용 무료, **에셋만 따로 재판매·재배포 금지**. 그래서
  원본을 공개 저장소에 두지 않는다. 출처 목록은 에셋 저장소의 README 에 있다.
- 이 저장소에는 조각 **이름과 자리**(`src/doll/art.gen.ts`, 자동 생성)만 있다.
  그림 파일은 `public/assets/doll/` 로 복사해 쓰고 커밋하지 않는다(.gitignore).
- 배포(GitHub Actions)는 읽기 전용 배포 키(`ASSETS_DEPLOY_KEY`)로 에셋 저장소의
  `doll/` 만 받아 `public/assets/doll/` 에 넣고 빌드한다.
- 그림이 없으면 그 조각만 비어 보이고 게임은 돈다. 테스트·lint 는 그림 없이 돈다.

### 왜 8등신에서 치비로 바꿨나

참고작(Hollywood Merge)을 따라 8등신 패션 아바타를 벡터로 그렸지만, 아이가
"재미없다" 고 했고 벡터 옷은 참고작과 비교가 됐다. 일러스트 팩을 찾아 보니 무료
성인 체형 팩은 네 살에게 맞지 않았고, 같은 작가의 치비(2~3등신) 팩이 얼굴·머리
색까지 갖춰 가장 잘 맞았다.

## 좌표계

인형은 **200 x 440** 상자에 선다. 팩의 모든 조각은 같은 판(444 x 700)에 그려져
있어서, 판을 상자에 한 번 맞추면 옷이 몸에 저절로 맞는다.

```
판 (sx, sy) → 인형 (x, y) = ((sx - 225) x 0.6875 + 100, (sy - 40) x 0.6875)
```

이 값은 `src/doll/art.ts` 의 `SRC` 와 에셋 저장소 `tools/build.py` 의 `K·CX·Y0`
두 곳에 있다. **둘을 같이 바꿔야 한다.** 굽는 쪽이 조각마다 여백을 잘라내고
잘린 자리를 인형 좌표로 적는다.

`src/doll/body.ts` 의 `A` 가 자리표다 (판에서 잰 값).

```
 y≈56   머리카락 꼭대기 (hairTop)
 y≈65   맨머리 꼭대기 (headTop)
 y≈182  눈
 y≈191  귓불 (왼쪽만 보인다 — 얼굴이 살짝 돌아 있다)
 y≈219  턱
 y≈230  목 밑 (목걸이)
 y≈275  허리
 y≈301  오른손 (살짝 들었다)  · 왼손 y≈327
 y≈358  무릎
 y≈428  발끝
```

### 벡터 소품 옮기기 (fit.ts)

왕관·날개·지팡이는 예전 8등신 좌표("벡터 틀")로 그려져 있다. 다시 그리지
않고 `XF = [배율, dx, dy]` 로 치비 머리·등·손에 옮긴다. `Shape.xf` 에 실려
그릴 때 적용된다. 왕관 공방이 보석 칸을 두드릴 때도 `xfPoint(XF.crown, …)` 로
같은 값을 쓴다 — 그림과 두드림이 어긋나지 않게.

## 층 번호

`composeDoll()` 이 이 순서로 조각을 이어 붙인다. **순서가 곧 앞뒤다.**

| 층 | 내용 |
|---|---|
| 10 | 날개 (`wings.back`) |
| 20 | 망토 천 (`cape.back`) |
| 25 | 뒷머리 — 머리 아이템, 없으면 기본 긴 생머리 |
| 30 | 몸 |
| 34 | 얼굴 (눈·속눈썹·눈썹·입·볼터치) |
| 38 | 기본 옷 (흰 티 + 분홍 치마) — **드레스를 입으면 생략** |
| 42 | 드레스 (위아래 조합·인어 꼬리 포함) |
| 46 | 구두 |
| 58 | 장갑·팔찌 |
| 60 | 목걸이 |
| 62 | 윗머리·앞머리 |
| 64 | 망토 깃 |
| 66 | 귀걸이 |
| 72 | 왕관·머리 장식 |
| 76 | 손에 드는 소품 |

일러스트 옷은 소매까지 한 장이라 예전의 팔·소매 층은 없다.
**기본 옷은 벗겨지지 않는다** — 아이가 옷을 다 벗기고 당황하지 않게.

## 색 바꾸기

- 드레스·구두·망토: 그림 픽셀의 색조를 돌린다(`retintPixels`). 검은 선·흰
  반사광·회색 그늘은 그대로 둔다. 결과는 `render/images.ts` 가 캐시한다.
- 머리: 팩에 그려진 **8색 그림을 바꿔 끼운다**(`HAIR_SHADES`). 금발·백발처럼
  밝기가 크게 다른 색이 색조 돌리기로는 어색하기 때문이다. 팩 머리가 아닌
  무지개 머리만 색조를 돌린다.
- 같은 그림에 색을 입힌 옷(`['dress6', '#7fb6f2']`)을 따로 한 벌로 셀 수 있다.
  팩 드레스가 적어서 공주 드레스 색을 늘리는 방법이다.

## 옷 한 벌 추가하기

1. 에셋 저장소 `tools/build.py` 의 `pick()` 에 `'이름': 팩 경로` 를 넣고 굽는다.
   ```bash
   cd ../leah_game_assets
   python3 -I tools/build.py ../leah_game          # doll/ 과 art.gen.ts 갱신
   cp -R doll/. ../leah_game/public/assets/doll/
   git add -A && git commit && git push            # 에셋 저장소
   ```
2. `src/doll/wardrobe.ts` 표에 한 줄을 넣는다.
   ```ts
   dress({ id: 'dress-mint-bell', name: '민트 종 드레스', color: 'teal', theme: 'flower' }, ['frou1', 'witch-top1']),
   ```
   앞에서 뒤 순서로 조각 이름을 적는다(치마 → 윗옷). 썸네일 영역은 조각을
   감싸도록 자동으로 잡힌다.

생성 그림(ChatGPT)을 넣을 때는 `gen/in/<파일>.png` 로 저장하고, `pick()` 대신
`build.py` 의 `GEN` 에 판(444 x 700) 위 자리 `(중심 x, 중심 y, 폭)` 을 적는다.
판 좌표의 머리 꼭대기 y≈122, 오른손 (338, 478), 어깨 y≈390. 기준 그림은
`python3 tools/reference.py` 가 만든다.

- **아이디는 절대 바꾸지 않는다.** 저장된 코디와 룩북이 아이디로 옷을 기억한다.
- `color` · `theme` 태그는 패션쇼 미션 조건에 쓰인다. 빠뜨리면 그 옷으로는
  "파란색 옷을 입어줘" 같은 미션을 깰 수 없다.
- `npm test` 가 데이터를 검사한다(모르는 그림 이름도 잡는다). 부팅할 때도
  `assertValidWardrobe` 가 한 번 더 본다 — 검은 화면 대신 무엇이 잘못됐는지
  글로 보여 준다.

## 표정

`faceShapes(expr)` 에 다섯 가지가 있다: `smile` · `happy`(감은 눈) · `wink` ·
`surprise` · `sparkle`(별 눈동자). 팩에 윙크 그림이 없어서 `wink` 는 `happy` 와
같다. 옷을 입히면 잠깐 `happy` 로 바뀌었다가 돌아온다.

## 그림 확인하기

```bash
npm run dev
open http://localhost:5173/leah_game/tools/wardrobe.html
```

옷 전부를 인형에 하나씩 입혀 한 판에 늘어놓는다. 새 옷을 넣으면 자동으로 붙는다.
`tools/preview.html` 은 기본 인형과 표정 5종을 크게 보여 준다.
